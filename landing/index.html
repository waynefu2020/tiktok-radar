Quick Start

无需复杂配置，填好环境变量，5 分钟跑起来。

# 认证
JWT_SECRET=your_jwt_secret

FAQ

常见问题

需要 TikHub 账号吗？

是的，需要注册 TikHub 并申请 API Key。TikHub 提供按量付费，日常监控成本通常在 $5–$20/月之间。

数据存在哪里？

数据存储在你自己的服务器上（SQLite），完全私有，不依赖任何第三方云服务。

支持哪些 TikTok 内容类型？

支持话题标签视频、关键词搜索视频、创作者主页视频。未来计划支持广告素材追踪。

AI 脚本拆解需要额外付费吗？

需要配置 OpenAI API Key（用于 Whisper 转写）和 Claude API Key（用于脚本分析）。按实际用量计费。

可以监控竞品 App 吗？

完全可以。在 App Manager 里添加竞品的 TikTok 话题标签，系统会自动抓取和分析对应 UGC 内容。

团队多人使用怎么配置？

内置用户管理系统，支持管理员创建成员账号，分配不同权限。适合 2-10 人的营销小团队。
